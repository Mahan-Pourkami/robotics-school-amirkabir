# مدرسه رباتیک امیرکبیر

نسخه‌ی تفکیک‌شده‌ی قالب سایت؛ HTML، CSS و JavaScript در فایل‌ها و پوشه‌های جدا قرار گرفته‌اند.

## ساختار پروژه

- `index.html` — ساختار صفحه
- `css/styles.css` — تمام استایل‌ها و واکنش‌گرایی
- `js/main.js` — تغییر پوسته روشن/تیره
- `js/robot.js` — صحنه سه‌بعدی بازوی رباتیک با Three.js
- `assets/images/` — محل قرار دادن تصاویر واقعی سایت

## اجرا

فایل `index.html` را با مرورگر باز کنید. برای اجرای مطمئن ماژول Three.js، بهتر است پروژه را با یک وب‌سرور محلی اجرا کنید؛ مثلاً در ریشه پروژه:

```bash
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید.

Three.js از CDN بارگذاری می‌شود و برای نمایش مدل سه‌بعدی به اینترنت نیاز دارد.

## نکته

فرم تماس در نسخه اصلی نمایشی است و برای دریافت واقعی درخواست‌ها باید به بک‌اند یا سرویس فرم متصل شود. بخش‌های عکس نیز جایگاه‌نما هستند و می‌توانید تصاویر خود را در `assets/images/` قرار دهید و مسیرشان را در HTML تنظیم کنید.
